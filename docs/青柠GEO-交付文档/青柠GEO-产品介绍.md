**困境 1：AI 内容同质化严重**

- ChatGPT、文心一言人人都在用，内容高度相似；
- 搜索引擎和 AI 平台开始限流 AI 生成内容；

**困境 2：传统 SEO 失效**

- 用户不再只用百度，而是问 ChatGPT、Kimi、豆包、DeepSeek；
- 传统 SEO 优化对 AI 平台无效；
- 错失 AI 平台带来的新流量。

**困境 3：多平台运营成本高**

- 百家号、头条号、网易号……逐个发布太耗时；
- 内容创作、发布、追踪收录，人力成本高；
- 小团队难以持续运营。

## 🎯 什么是 GEO？为什么需要它？

### GEO ≠ SEO

GEO（Generative Engine Optimization，生成式引擎优化）是针对 AI 搜索引擎的内容优化策略。随着 ChatGPT、DeepSeek、Kimi、通义千问等 AI 平台成为用户获取信息的重要渠道，品牌需要确保自己的内容能被这些 AI 引擎「收录」并推荐给用户。

| 对比维度 | SEO（搜索引擎优化） | GEO（生成式引擎优化） |
| --- | --- | --- |
| 面向平台 | 百度、Google 等传统搜索引擎 | 豆包、DeepSeek、文心一言、Kimi 等 AI 搜索平台 + 传统搜索引擎 |
| 优化重点 | 关键词、外链、网站结构 | 内容自然度、原创度、信息密度 |
| 达成效果 | 搜索结果排名靠前 | AI 平台愿意引用、推荐你的内容 |

### 什么是 GEO 优化平台？

青柠GEO 是一套完整的 AI 内容创作与优化工具，帮助你：

- **管理蒸馏词**（核心关键词），让 AI 引擎更好地理解你的品牌；
- **利用 AI 自动拓展问题**，覆盖用户可能的搜索意图；
- **基于企业画像和模板，批量生成**高质量文章；
- **一键发布**到百家号、头条号、知乎等多个自媒体平台；
- **检测收录状态**，追踪各 AI 平台是否已收录、提及你的内容。

### 青柠GEO 的价值

- ✅ **创作**符合 GEO 规范的高质量内容（去 AI 味、高原创度）；
- ✅ **发布**一键分发到多个自媒体平台；

## 🔑 核心概念：蒸馏词

**蒸馏词是 GEO 优化的核心**，帮助你的品牌被 AI 搜索引擎提及和推荐。

### 概念链路

```
核心蒸馏词（如：工业机器人）
        ↓ AI 自动拓展
拓展问题（如：哪家好？）
        ↓ 内容发布与 AI 引用
AI 提及（推荐 xx 科技）
```

| 概念 | 说明 | 示例 |
| --- | --- | --- |
| 核心蒸馏词 | 品牌核心关键词，GEO 优化的起点 | 工业机器人、家用小型冷藏柜怎么选 |
| 拓展问题 | AI 基于蒸馏词自动拓展的用户搜索问题 | 「哪家好？」「怎么选？」「十大品牌推荐」 |
| 品牌植入词 | 品牌名称/产品词，**AI 创作时自动植入，提及检测时匹配判断** | xx 科技、吾美 |
| 提及率 | 品牌在 AI 平台回答中被提及的比例 | 提及 3 / 检测 6 = 50% |

## 🚀 核心功能

### 1. 智能工作台 —— AI 可见度一屏总览

- **AI 可见度报告**：生成 GEO 分析报告后，自动展示品牌在各 AI 平台的**可见度、引用率、竞品 SOV、情感倾向与行动任务**，支持输出归因报告；
- **品牌事实库 / GEO 周报**：沉淀品牌事实素材，按周输出 GEO 优化周报；
- **核心指标卡**：蒸馏词数、拓展问题数、检测次数、创作文章数、已提及数与提及率；
- **AI 平台表现**：覆盖豆包、DeepSeek、腾讯元宝、通义千问、文心一言、Kimi、智谱清言、ChatGPT 等 8 大平台，逐平台展示提及率与授权状态；
- **今日待办 + 智能推荐**：自动识别发布失败、待扩展蒸馏词、待发布文章等事项，基于待办分析给出处理建议。

### 2. 蒸馏词管理（AI 内容选题助手）—— GEO 优化的起点

- **关键词库管理**：手动导入、批量添加、分类标签、编辑删除，支持搜索与提及状态筛选；
- **AI 智能扩展**：基于种子词/核心蒸馏词自动生成拓展问题与长尾关键词（一个蒸馏词可拓展数十个问题）；
- **品牌植入词绑定**：每个蒸馏词绑定品牌植入词，创作时自动植入、检测时自动匹配；
- **热度分析**：实时获取搜索热度、竞争度数据；
- **选题推荐**：智能推荐高价值选题；
- **效果回链**：每个蒸馏词关联拓展问题数、提及率、文章数，形成「词 → 内容 → 提及」闭环。

> 适用场景：GEO 优化、内容规划、竞品分析。

### 3. AI 智能写作 —— 高效生产高质量原创内容

- **双内容形态**：**长文章**（适合 SEO 内容、专题文章、深度输出）+ **图文内容**（适合朋友圈、种草笔记、平台动态、社媒分发）；
- **三种创作方式**：AI 创作（全自动）、AI 编写（半自动）、手动创作；
- **多模板支持**：行业问答、产品评测、经验分享等 6 大模板，20 个模板含 9 个系统预设；
- **品牌画像系统**：配置企业/产品画像（支持多画像），AI 创作更精准、自然植入品牌信息；
- **知识库引用**：上传企业资料作为事实依据，AI 创作时引用，内容更有据可依；
- **去 AI 味优化**：智能规避 AI 常用套话，内容更自然真实；
- **相似度检测**：自动检测内容原创度，确保内容独一无二；
- **审核机制**：文章需经「待审核 → 已审核」人工审核流，**发布前必须人工审核**。

**创作流程：**

```
选择关键词 → 选择画像模板 → AI 生成内容 → 人工审核 → 一键发布
```

> 适用场景：企业官网内容、自媒体运营、GEO 优化内容生产。

### 4. 素材中心 —— 统一的内容资产管理

| 模块 | 说明 |
| --- | --- |
| 图片素材 | 管理 AI 创作配图，分类管理、批量上传、智能搜索 |

| 知识库 | 上传资料，AI 创作时引用为事实依据 |

### 5. 媒体账号管理 —— 多平台账号统一授权

- **支持平台**：百家号、头条号、网易号、搜狐号、企鹅号、知乎、简书、掘金、CSDN 等；
- **OAuth 授权**：安全便捷，无需保存密码；
- **账号分组**：按品牌、业务线分组管理；
- **状态监控**：授权过期自动提醒。

### 6. 发布任务管理与自动托管 —— 一键多平台分发

- **批量发布**：一篇内容同时发布到多个平台；
- **定时发布**：预约发布时间，自动执行；
- **自动托管**：托管式自动执行发布任务，省去人工盯守；
- **发布记录**：完整历史，支持查看、编辑、重发；
- **失败重试**：自动重试确保成功率，失败任务在工作台置顶提醒。

### 7. 提及检测（收录检测）—— AI 平台效果追踪

- **8 大 AI 平台**：豆包、DeepSeek、腾讯元宝、通义千问、文心一言、Kimi、智谱清言、ChatGPT，以及百度、搜狗等搜索引擎；
- **浏览器扩展**：配合浏览器扩展一键快速检测；
- **智能批量检测**：选择蒸馏词或问题后，批量检测提及/收录状态；
- **提及率口径**：按「品牌植入词匹配」统计提及率，支持按蒸馏词、按平台维度查看；
- **分享报告**：生成可分享的收录报告链接。

> 核心价值：量化 GEO 效果，优化内容策略。

### 8. 网站推送 —— 推送文章到自己的网站

## 💡 技术优势

### 六层技术架构

```
采集层：Prompt 库 + 多模型 API（OpenAI / Anthropic / Perplexity + 国内元宝 / 豆包 / DeepSeek）
        ↓
执行层：Agent 并发请求 → 原始答案 + 引用溯源 → 结构化入库
        ↓
分析层：提及提取 / 竞品对比 / 情感判断（LLM-as-a-Judge）
        ↓
知识资产：企业知识库 → 切片 → Embedding → 向量库（Milvus / pgvector / Faiss）
        ↓
优化层：内容评分（EEAT）、Schema / llms.txt 校验、结构修复清单
        ↓
展示层：仪表盘（可见度 / 引用率 / SoV / 情感）、归因报告
```

| 层级 | 职责 | 关键能力 |
| --- | --- | --- |
| 采集层 | 多模型答案采集 | Prompt 库 + 多模型 API（**公网 API + 私有化部署双模式**）：OpenAI、Anthropic、Perplexity + 国内元宝、豆包、DeepSeek |
| 执行层 | 并发采集与入库 | Agent 并发请求，获取原始答案与**引用溯源**，结构化入库；监测采用**混合模式**（官方 API + 自建账号池 + 浏览器自动化） |
| 分析层 | 效果分析 | 提及提取、竞品对比、情感判断（**LLM-as-a-Judge**）、竞品逆向研究、多模态分析 |
| 知识资产 | 企业知识沉淀 | 企业知识库 → 切片 → Embedding → 向量库（**Milvus 大规模 / pgvector / Faiss 离线调优**） |
| 优化层 | 内容与结构优化 | 内容评分（**EEAT**）、Schema / llms.txt 校验、结构修复清单 |
| 展示层 | 数据可视化 | 仪表盘（可见度 / 引用率 / SoV / 情感）、归因报告、BVI 品牌可见性指数 |

> 注：六层架构为青柠GEO 的技术设计蓝图；向量库选型等组件的具体落地方案以实际交付版本为准（详见《软件建立说明书》）。

### 技术选型决策

| 选型项 | 方案对比 | 选型策略 |
| --- | --- | --- |
| 向量库 | **Milvus**（大规模在线检索） vs **Faiss**（离线调优、嵌入式） | 按数据量级与部署形态选择，兼顾 pgvector 轻量方案 |
| AI 平台监测方式 | **官方 API**（成本高、限额、难批量） vs **自建账号池 + 浏览器自动化**（主流做法） | **混合模式**：兼顾成本、批量规模与合规 |
| 模型接入 | **公网 API**（OpenAI / Anthropic / 国内模型） + **私有化部署** | 双模式并存，敏感数据场景可切换私有化模型 |

> 合规提示：账号池与浏览器自动化监测须遵守各平台服务条款，控制访问频率，合规运营。

### Phase B 技术路线图（多模态进阶）

| 阶段 | 内容 |
| --- | --- |
| Phase B.1 | **CLIP + YOLO 视觉识别**：接入 OpenAI CLIP 进行图文匹配，YOLO v8 进行 Logo / 物体检测，支持品牌 Logo 自动识别 |
| Phase B.2 | **Whisper v3 语音转写**：接入 Whisper large-v3 多语言 ASR，自动提取品牌名 / 竞品名提及 |
| Phase B.3 | **Video-LLaVA 视频理解**：多模态大模型对视频关键帧进行语义理解，自动生成视频摘要 |
| Phase B.4 | **跨模态融合引擎**：构建多模态特征融合层，输出统一的品牌可见性指数（BVI），支持文本 + 图像 + 视频 + 音频联合分析 |

### GEO 专业术语速览

| 术语 | 说明 |
| --- | --- |
| SoV（Share of Voice） | 声量份额：品牌内容在目标问题的 AI 回答中占比，用于竞品对比 |
| 引用率 | AI 回答中引用/推荐品牌内容链接的比例，衡量「被 AI 当作信源」的程度 |
| 情感倾向 | AI 回答中对品牌的情感判断（正面 / 中性 / 负面） |
| EEAT | Google 内容质量评估框架：Experience（经验）、Expertise（专业）、Authoritativeness（权威）、Trustworthiness（可信），此处用于内容评分 |
| LLM-as-a-Judge | 用大模型对内容/答案进行自动化评估打分的机制 |
| llms.txt | 面向 AI 引擎的站点内容说明文件规范，帮助 AI 更好地理解与索引站点结构 |
| Embedding / 向量库 | 将知识切片向量化存储（Milvus / pgvector / Faiss），支撑语义检索与知识引用 |

### 架构设计

- **前后端分离**：Vue 3 + ThinkPHP 8，性能卓越；
- **模块化设计**：易于扩展；
- **API 优先**：支持第三方集成。

### 安全与合规

- **JWT 认证**：Token 机制安全可靠；
- **数据加密**：敏感信息加密存储；
- **权限控制**：细粒度权限管理（管理员/普通用户/代理商/子客户四级角色）；
- **内容合规**：仅用于合规内容创作与分发，发布前必须人工审核。

### 性能优化

- **缓存机制**：Redis 缓存响应快；
- **异步处理**：耗时任务（批量创作、批量检测）不阻塞；
- **CDN 加速**：静态资源快速分发。
