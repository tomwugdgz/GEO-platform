## 1. 文档编号与命名规则

- **编号格式**：`QNGEO-S<阶段号>-<序号>`，例：`QNGEO-S2-02` = 阶段 2 第 2 份文档《指标定义与计算口径手册》；
- **文件命名**：`QNGEO-S<阶段号>-<序号>_<文档简称>_v<版本>.md`；
- **版本规则**：草稿 `0.x` → 评审通过后 `1.0` 基线；每次基线变更 +0.1 并登记变更记录；
- **状态取值**：`草稿 / 评审中 / 已批准 / 已归档 / 已废弃`。

## 3. 模板使用规范（适用于全部模板）

1. **文档控制块**：每份正式文件开头必须包含本文档控制块（编号 / 版本 / 状态 / 编制人 / 评审人 / 批准人 / 日期 / 密级）；
2. **变更记录**：基线化后任何内容修改须登记变更记录表（版本 / 日期 / 修改人 / 修改摘要 / 影响范围）；
3. **占位符约定**：`【待填写：说明】` 表示必须由责任人填写的内容，交付前全文检索 `【` 确认无遗漏；
4. **示例行约定**：模板中以 `（示例）` 标注的表格行仅为填写示范，编制时替换为真实内容；
5. **评审流程**：起草（状态=草稿）→ 评审会（状态=评审中）→ 修订 → 批准（状态=已批准，升基线版本）→ 归档至项目资料库；
6. **敏感信息检查**：所有"客户可见"文档在发出前，须确认不含内部成本、人员安排、未确认承诺与内部风险判断（对照《青柠GEO-产品介绍.md》附则执行）。

## 4. 交付协同要点（贯穿 7 阶段）

- 阶段 1 合规风险专章为**立项一票否决项**：AI 对话采集（绕过登录 / 批量爬取）属灰色地带，方案必须遵循「合规优先」三支柱——官方 API 优先 + 用户自有账号授权 + robots.txt 尊重；
- 阶段 2 指标口径手册为**交付命脉**：提及率 / 引用率 / AVI 指数等口径一经客户确认即冻结，变更须走口径变更流程；
- 阶段 4（数据与知识资产）为**最易低估环节**：Prompt 库、知识库、Golden Set 的质量直接决定阶段 6 评测结果，建议投入不低于总工期的 15%；
- 阶段 7 模型调用费为**主要运营成本**：成本控制手册须在上线前完成审批。
