## 1. 部署架构（文字基线，交付正式架构图）

```
负载入口（Nginx / SLB）
  ├─ Web 前端（Vue 3 构建产物，静态托管 / CDN）
  ├─ API 服务（ThinkPHP 8，可水平扩展）
  ├─ 队列 Worker（采集执行 / 分析引擎 / 报告生成）
  ├─ 调度器（定时任务：快照聚合 / 周报 / 告警判断）
  ├─ MySQL（业务库）+ Redis（缓存/队列）
  ├─ 向量库（Milvus / Faiss / pgvector，选型见 ADR-01）
  ├─ 多模态推理（可选，GPU：CLIP/YOLO/Whisper ≥8G；Video-LLaVA ≥16G）
  └─ 浏览器扩展（授权会话检测载体，客户端侧）
```
