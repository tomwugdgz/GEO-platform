# 模板 S4-03《ETL 处理脚本目录》

## 文档控制块

> 同前（编号 QNGEO-S4-03）。本目录为**脚本索引与规范文档**（不含代码实现）。

## 1. ETL 流水线（六环节）

```
原始资料 → 清洗 → 实体消歧 → 去重 → 切片 → 打标 → 同义归集（三元组体系）
```

| 环节 | 处理内容 | 输入 → 输出 | 脚本编号 | 质量门禁 |
| --- | --- | --- | --- | --- |
| 清洗 | 去噪 / 格式归一 / 乱码处理 | 原始文档 → 干净文本 | ETL-01 | 【】 |
| 实体消歧 | 品牌名 / 产品名 / 别名统一 | 干净文本 → 消歧文本 | ETL-02 | 品牌名消歧准确率 ≥【】% |
| 去重 | 内容级去重（SimHash / embedding 相似度） | 消歧文本 → 唯一文本 | ETL-03 | 重复率 ≤【】% |
| 切片 | 按分块策略（S3-05）切分 | 唯一文本 → chunk | ETL-04 | 【】 |
| 打标 | 类目 / 品牌 / 来源标签 | chunk → 带元数据 chunk | ETL-05 | 【】 |
| 同义归集 | 同义实体三元组归集（实体-关系-属性） | 标签 chunk → 知识条目 | ETL-06 | 【】 |

## 2. 脚本运行规范

- 调度方式：【手动触发 / 定时任务】；幂等性要求；失败重跑策略；
- 数据血缘：每批次记录输入指纹 → 输出指纹【待填写】。

# 模板 S4-05《Golden Set 评测集 v1》

## 文档控制块

> 同前（编号 QNGEO-S4-05）。**Golden Set = 人工标注的「标准答案」，是 LLM-as-a-Judge 打分基准，质量决定评测可信度。**

## 1. 评测集构成

| 组成部分 | 数量 | 标注内容 | 用途 |
| --- | --- | --- | --- |
| 标准问答对 | 【如 200 条】 | 人工核定的优质回答 | Faithfulness 忠实度基准 |
| 引用标准 | 【如 100 条】 | 人工判定应引用的信源 | Citation Rate 校验 |
| 品牌提及标准 | 【如 200 条】 | 人工标注提及/未提及/正确表述 | 提及提取准确率、信息准确率 |

## 2. 标注规范

| 规范项 | 要求 |
| --- | --- |
| 标注人 | ≥2 人独立标注，分歧仲裁机制【待填写】 |
| 标注一致率 | 双标一致率 ≥【如 90%】方可入库 |
| 抽检 | 评审阶段按 ≥10% 抽检 |
| 版本管理 | v1 基线冻结，变更需登记 |

## 3. 评测指标（供 S6 校验使用）

| 指标 | 定义 | 目标值 |
| --- | --- | --- |
| Faithfulness（忠实度） | 生成/提取内容与 Golden 标准的一致程度 | ≥【】 |
| Citation Rate | 引用命中 Golden 标准引用的比例 | ≥【】 |
| Precision@k | Top-k 提取结果的准确率 | ≥【】 |
