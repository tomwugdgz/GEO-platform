# 模板 S3-06《内容评分 / EEAT 规则引擎设计》

## 文档控制块

> 同前（编号 QNGEO-S3-06）。

## 1. EEAT 四维评分框架

| 维度 | 评估问题 | 评分信号（示例） | 分值权重 |
| --- | --- | --- | --- |
| Experience 经验 | 是否体现真实使用经验 | 一手案例 / 数据 / 时间细节 | 【】 |
| Expertise 专业 | 是否体现专业深度 | 术语准确度 / 深度论述结构 | 【】 |
| Authoritativeness 权威 | 是否有权威背书 | 引用来源质量 / 作者资质标注 | 【】 |
| Trustworthiness 可信 | 信息是否可信可验证 | 数据可溯源 / 联系与披露信息 | 【】 |

## 2. 评分执行方式

- 规则引擎（可量化信号）+ LLM-as-a-Judge（语义维度）混合打分；
- 输出：0-100 分 + 维度分解 + 修复建议（结构修复清单）。

## 3. 与优化建议的联动

> 评分结果 → 结构修复清单生成规则表【待填写：如「缺引用来源 → 建议补充引用」】。
