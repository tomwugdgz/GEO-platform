## 2. Git 提交规范

- Commit 格式：`<type>: <subject>`，type 取 `feat / fix / refactor / test / docs / chore`；
- 关联需求：commit message 或 PR 描述须带 `FR-XXX` / Bug 编号，实现需求追溯。

## 3. 评审与合并

| 事项 | 要求 |
| --- | --- |
| Code Review | ≥1 人评审（核心模块 ≥2 人）；评审清单【待填写】 |
| PR 粒度 | 单 PR ≤【如 400 行】变更 |
| CI 门禁 | 单测通过 / Lint 通过 / 安全扫描通过 |

## 4. 测试要求（开发自测）

- 核心逻辑（提取引擎 / 口径计算 / 权限校验）单测覆盖率 ≥【如 70%】；
- 新增 API 须附契约测试（对齐 OpenAPI）。
