# 模板 S2-02《指标定义与计算口径手册》 ★最重要

> 本手册是 GEO 交付的命脉：口径一经客户确认即**冻结**，避免交付验收阶段扯皮。

## 文档控制块

> 同前（编号 QNGEO-S2-02）。**评审要求：客户接口人共同签署。**

## 1. 指标总表（核心口径）

| 指标 | 定义 | 计算公式 | 数据源 | 统计粒度 | 基准值 | 优秀值 |
| --- | --- | --- | --- | --- | --- | --- |
| **提及率** | 品牌在 AI 回答中被提及的比例 | **提及品牌次数 ÷ 总回答数** | 原始答案表 | Prompt × 平台 × 时间窗 | **15%-25%** | **≥60%** |
| 引用率 | AI 回答引用品牌内容链接的比例 | 含品牌链接的回答数 ÷ 总回答数 | 引用记录表 | 同上 | 【待填写】 | 【】 |
| 推荐排名 | 品牌在推荐列表中的位次 | 品牌排序位次（多次检测取中位数） | 提取结果 | 同上 | 【】 | 【】 |
| 内容抓取率 | 品牌内容被 AI 平台抓取收录的比例 | 被抓取内容 URL 数 ÷ 提交内容 URL 总数 | 收录检测 | 【】 | 【】 | 【】 |
| 语义匹配度 | 回答语义与品牌主张的匹配程度 | 【待填写：Embedding 相似度方案】 | 分析引擎 | 【】 | 【】 | 【】 |
| 信息准确率 | AI 表述品牌信息的准确程度 | 准确表述数 ÷ 品牌相关表述总数 | Golden Set 比对 | 【】 | 【】 | 【】 |

## 2. AVI 综合指数（合成指数）

| --- | --- | --- | --- |
| 提及率 | 【待填写：如 30%】 | 【min-max / 分段】 | 【】 |
| 引用率 | 【如 25%】 | 【】 | 【】 |
| 推荐排名 | 【如 15%】 | 【位次转分】 | 【】 |

## 3. 指标分层框架（二选一或并用，须明确）

### 3.1 漏斗分层（A 方案）

| 层级 | 覆盖指标 | 回答的问题 |
| --- | --- | --- |
| 曝光层 | 提及率、内容抓取率 | AI 是否提到我 |
| 认知层 | 引用率、推荐排名 | AI 如何呈现我 |
| 行为层 | 点击 / 转化归因 | 用户是否因此行动 |
| 转化层 | 线索 / 成交归因 | 是否产生生意 |

### 3.2 质量分层（B 方案）

| 维度 | 覆盖指标 |
| --- | --- |
| 可见度 | 提及率、SoV |
| 归因质量 | 引用率、信息准确率 |
| 查询覆盖 | Prompt 覆盖率、类目覆盖 |
| 情感 | 正面 / 中性 / 负面占比 |

## 4. 统计与计算规则（防扯皮细则）

- **回答数口径**：一次检测 = 1 Prompt × 1 平台 = 1 回答；失败的调用**不计入分母**，须记录失败原因【待确认】；
- **模型随机性处理**：固定 Prompt 集回归基线测试**跑 3 次取平均**（见 S6-01）；
- **提及判定**：品牌植入词精确匹配 + 别名/消歧词表（消歧规则见 S6-02 用例）；
- **时间窗**：默认统计周期【待填写：日 / 周 / 月】，快照落库于指标快照表；
- **平台授权状态**：未授权平台不纳入指数分母，仪表盘须明示授权率。

## 5. 口径冻结与变更管理

| 事项 | 规则 |
| --- | --- |
| 冻结时点 | 需求评审通过 + 客户签署 |
| 变更发起 | 《口径变更申请》：变更内容 / 影响的历史数据范围 / 影响的已交付报告 |
| 变更审批 | 【待填写：产品负责人 + 客户接口人双签】 |
| 生效方式 | 新口径自生效日起对新数据适用；历史数据【重算 / 并存标注，待确认】 |

# 模板 S2-04《核心业务流程图》

## 文档控制块

> 同前（编号 QNGEO-S2-04）。交付形式：流程图（mermaid / 图片）+ 文字步骤，此处给文字基线。

## 1. Prompt 执行流（主流程）

```
选择 Prompt 集（固定集 / 临时集）
  → 任务创建（含平台清单、频率、租户）
  → 调度引擎分发（Agent 并发 + 限流 + 重试）
  → 多模型 Adapter 调用（合规通道：官方 API / 授权会话）
  → 原始答案 + 引用溯源入库
  → 提及 / 引用 / 情感提取（规则 + LLM Judge）
  → 指标聚合 → 指标快照落库
  → 仪表盘刷新 / 告警判断
```

> 异常分支：调用失败（重试 3 次 → 标记失败，不计入分母）；限流（降级队列）；授权过期（暂停通道 + 提醒）。

## 2. 报告生成流

```
选择时间窗 + 品牌 + 竞品集
  → 拉取指标快照
  → 竞品对比计算（SoV / 排名差）
  → 优化建议生成（EEAT 评分 + 结构修复清单）
  → 渲染报告模板
  → 导出（PDF / Excel / 分享链接）→ 客户确认
```

## 3. 流程图交付要求

- 每张流程图须标注：角色泳道、异常分支、系统边界（前端 / 后端 / 外部 API / 浏览器扩展）；
- 交付物：【待填写：mermaid 源文件 / 图形文件链接】。
