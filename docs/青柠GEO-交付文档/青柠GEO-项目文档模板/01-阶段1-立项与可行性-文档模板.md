## 5. 合规风险专章（一票否决项）

### 5.1 灰色地带分析

| 行为 | 风险定性 | 平台条款冲突点 |
| --- | --- | --- |
| 绕过登录批量爬取 AI 对话 | **灰色 / 高风险** | 违反平台服务条款，存在账号封禁与法律风险 |
| 浏览器自动化访问公开页面 | 中风险 | 需控制频率、尊重 robots.txt |
| 官方 API 调用 | 低风险 | 受限额与计费约束 |
| 用户自有账号授权（OAuth） | 低风险 | 用户授权范围内使用 |

### 5.2 合规优先方案（三支柱）

1. **官方 API 优先**：具备官方 API 的平台一律走官方通道；
2. **用户自有账号授权**：浏览器扩展基于用户本人登录会话执行检测，账号归属用户、责任边界清晰；
3. **robots.txt 尊重**：自动化访问前校验 robots 规则，控制 QPS，配置 UA 标识。
